# Обязательный агентский фреймворк

Этот проект использует фреймворк `.kilocode`. Все агенты и автоматизированные исполнители обязаны соблюдать его инструкции при любой работе с проектом.

## Обязательный порядок работы

1. Перед анализом, планированием, изменением кода, отладкой или проверкой прочитать `.kilocode/rules/rules.md` целиком.
2. Для задачи, требующей проектирования, создания или рефакторинга кода, сначала загрузить и применить `.kilocode/skill/mode-architect/SKILL.md`.
3. После утверждения плана перед реализацией загрузить `.kilocode/skill/mode-code/SKILL.md`.
4. При ошибках, падении тестов или диагностике загрузить `.kilocode/skill/mode-debug/SKILL.md`.
5. После реализации, когда применимо, выполнить независимую проверку по `.kilocode/skill/mode-qa/SKILL.md`.
6. Для специальных задач применять профильные навыки из `.kilocode/skill/` (`data-transform`, `devplan-protocol`, `document-protocol`, `graph-protocol`) в дополнение к режимным навыкам.

## Приоритет и контроль

Правила `.kilocode/rules/rules.md` обязательны для артефактов проекта: кода, тестов, планов, документации и исправлений. Нельзя приступать к фазе работы без предварительного чтения соответствующего навыка. При противоречии с явными инструкциями пользователя приоритет имеют инструкции пользователя; во всех остальных случаях действует `.kilocode`.

При работе с подагентами в задаче явно указывать им на обязательное чтение этого `agent.md` и нужного навыка из `.kilocode/skill/`.
